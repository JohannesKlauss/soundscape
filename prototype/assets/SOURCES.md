# Private prototype imagery

These are illustrative internet images for local design exploration only. They are **not production assets**, have not been cleared for distribution, and must not be copied into the native application or a release.

- `tavern.webp`: fantasy tavern artwork, [source page](https://wallhaven.cc/w/odww35), [image](https://w.wallhaven.cc/full/od/wallhaven-odww35.jpg). The source attributes the artwork to [atomiiii on ArtStation](https://www.artstation.com/artist/atomiiii). Resized to 1600 × 900 WebP for this prototype.
- `harbor.webp`: fantasy harbor/dock artwork, [source page](https://wallhaven.cc/w/vmx218), [image](https://w.wallhaven.cc/full/vm/wallhaven-vmx218.jpg). The image bears Lian / liangaizhen.com attribution. Resized to 900 × 409 WebP for this prototype.

The same artwork is cropped differently across example sounds; it does not represent actual imported media or generated artwork.
